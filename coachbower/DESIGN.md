# Design

Classic coaching site, done properly. Dark header and hero, light reading sections, one brand pink.

## Colour

| Token | Value | Use |
|---|---|---|
| `--ink` | #131313 | header, hero, dark sections, footer |
| `--paper` | #f4f4f2 | default page ground |
| `--white` | #ffffff | about, stories, article pages |
| `--text` / `--text-2` | #161617 / #4f4f55 | body and secondary text on light |
| `--pink` | #ff1289 | brand: CTA band, accents on dark, large display type |
| `--pink-strong` | #cc0066 | buttons and links on light (passes AA with white and on paper) |

Pink #ff1289 never carries small text on light, and small white text never sits on it.

## Type

Archivo (Google Fonts, variable width + weight), one family:

- Display (h1, h2, story names): weight 850, `font-stretch: 68%`, uppercase, line-height ~0.94.
- Body: normal width, 18px, line-height 1.6. Articles 19.5px / 1.72 with a ~700px measure.
- Google review cards use Roboto/Arial on purpose so they read as Google reviews.

## Components

- Pill buttons (`.btn`, `.btn-ghost`, `.btn-light`), arrow icon nudges on hover.
- Icons: inline SVG, 24 grid, 1.75 stroke (see `I` in the build script).
- Google review card: white, 12px radius, Google shadow, avatar, 5 stars, G mark, clamps long text with "Read more".
- "The gap" diagram: physio | rehab + strength | personal training; the pink bar fills once on scroll (the only scroll animation).
- Header: Home, Client stories, Helpful resources dropdown (Blog, 12 Isometrics guide), Get in touch.

## Source

Pages are generated by `_build/build.cjs` from `_build/b1.json` + `b2.json` (his Squarespace blog export) and `_build/style.css`. Run `node _build/build.cjs .` from this folder to rebuild.
